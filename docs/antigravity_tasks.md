# Tasks for Antigravity on the owner's desktop

Things the cloud session cannot reach (logins, rate limits, blocked sites). Each block below is one prompt to paste
into Antigravity on the owner's home laptop. Each one writes a **small markdown summary in our own words** into the
CAIIB repo on a new branch and opens a PR, so the next cloud session can read it. Raw PDFs, videos and screenshots
never go into git.

Rules for every task (repeat them in the prompt, already included below):
- Only public pages or the owner's own logins. Do not get around paywalls, logins or download blocks.
- Do not copy anyone's explanations, slides or full question text. Record **topics and question shapes** in our own
  words (e.g. "cross-rate bid calculation from USD/INR and GBP/USD quotes").
- Never fill a lead form with the owner's details without the owner confirming on screen first.
- No personal data of other people (names, phone numbers) in the output.

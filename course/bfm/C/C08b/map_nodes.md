# C08b · Mind Map Nodes
Module C Mind Map ("The bank's trading desk"), Branch 10 (Derivatives), in order of appearance in C08b_script_class:


1. FRA (N043a) — OTC, cash-settled, 1 future period, discounted upfront settlement.
2. IRS (N043a) — Multi-period net interest stream, no principal exchange; plain-vanilla, basis swap, OIS (FBIL MIBOR / SORR), market-maker warehousing.
3. Swaps in ALM (N060a) — Position × rate-view decision grid (pay fixed if rates rising; receive fixed if rates falling), bond-book hedge (Pay Fixed IRS / Short IRF), closing repricing & FC gaps.
4. Currency swaps (N082a) — Principal exchanged; 3 types (POS, COS, full CCS), 5 swap types card, and short-term USD/INR FX swap funding (principal only, near + far leg).

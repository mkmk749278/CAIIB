# B03 map nodes

Module B map: B03 draws **branch 5 "Statistics"**. The lesson map grows four nodes:

1. Mean and deviation: mean = sum ÷ n; deviation = value − mean; deviations always add to 0
2. Variance and SD: variance = Σ(deviation²) ÷ n, in squared units; SD = √variance, in real units, the typical
   swing = risk; ÷ (n − 1) only for a "sample"; shortcut mean of squares − mean²
3. Mean–variance and the bell: same mean → lower SD; same SD → higher mean; both differ → lower CV (SD ÷ mean);
   ±1σ ≈ 68%, ±2σ ≈ 95%, ±3σ ≈ 99.7%; one tail 1.65σ (95%), 2.33σ (99%); Basel VaR 99% one-tailed
4. Volatility over time: σ(T) = σ(1) × √T; long → short ÷ √T; year → n days × √(n ÷ days in year); days = what the
   question says; Basel 1996: scale to 10 days by √time

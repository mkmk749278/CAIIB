A00 voice · one teacher

One voice, in order. Each part is one generation in ElevenLabs text to speech.

How to use it
  • Pick one voice for the teacher (e.g. Prithvi) and keep it, with the same settings, for every part.
  • For each part: tap Copy, paste into text to speech, tap Generate, download it as the file name shown.
  • If the app says the text is too long, tell Claude and the parts will be made smaller.
  • Listen to the first minute of part 1 before doing the rest. Each generation uses credits.
  • Say: FEMA "FEE-ma", FERA "FEE-ra", FEDAI "fe-DYE", LERMS "lerms"; R-B-I, O-T-C, F-B-I-L letter by letter.

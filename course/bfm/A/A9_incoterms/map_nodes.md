# A9 Incoterms map nodes (Module A map, branch "Trade documents (LC, A4)")

1. Incoterms = ICC rules, 11, version 2020 (in force 1 Jan 2020); three letters + place + version
2. Decide three things: delivery/risk point · costs · export/import clearance. Not: price, payment, title
3. The road (7 stations): seller's premises · carrier · alongside ship · on board · arrived · unloaded · import cleared
4. Groups: E (EXW) · F (FCA, FAS, FOB) · C (CFR, CIF, CPT, CIP: risk early, cost to destination) · D (DAP, DPU, DDP)
5. Mode: any mode = EXW FCA CPT CIP DAP DPU DDP (7); sea/inland waterway = FAS FOB CFR CIF (4); containers → FCA/CIP
6. Least seller duty EXW, most DDP; export clearance seller except EXW; import clearance buyer except DDP; DAT → DPU
7. Insurance: only CIF (Clauses C min) and CIP (Clauses A); ≥110% of CIF/CIP value (UCP 600 Art. 28)

A1 dialogue · live class

For ElevenLabs multi-speaker text to speech. Each part is one generation, with turns in speaking order.

How to use it
  • Pick three voices once: Teacher (e.g. Prithvi), Meera (e.g. Adhya), Ravi (a second, different male voice).
  • For each turn below: tap Copy, add a speaker card with that voice in the app, paste. Same order, top to bottom.
  • When a part's turns are all in, tap Generate, then download it as the file name shown (part_1.mp3 …).
  • Start a fresh page in the app for the next part. Keep the same three voices and settings.
  • If the app says the text is too long, tell Claude and the parts will be made smaller.
  • Listen to the first minute of part 1 before doing the rest. Each generation uses credits.
  • Say: FEDAI "fed-eye", Nostro "noss-tro". "Into" means times.
